                  Conexión con GitHub 
                  
    
                  

      
                  
        Esta copia no puede publicar
        Está abierta dentro de Claude, que bloquea las conexiones salientes. La misma consola publicada en tu GitHub Pages sí publica sola. Acá sigue funcionando todo lo demás: leer la APK, validar y copiar.
      
                  

      
                  
        
        
      
                  
      
                  
        
        
      
                  

      
      

      
                  
        
        
        
      
                  
      
                    
      
                    

      
                    
        Cómo sacar el token (una sola vez)
        
                      
          
                    1. Entrá a github.com/settings/personal-access-tokens/new con tu cuenta.
                      2. 
          
                    2. Ponele un nombre (por ejemplo consola-otv) y elegí cuándo vence. Cuando vence deja de andar y sacás uno nuevo igual que este.
                      3. 
          
                    3. En Repository access elegí Only select repositories y marcá tv-digital-os-config. Así el token no toca ningún otro repositorio tuyo.
                      4. 
          
                    4. En Permissions → Repository permissions buscá Contents y ponelo en Read and write. Es el único permiso que hace falta: alcanza para los archivos y para las publicaciones donde van las APK.
                      5. 
          
                    5. Generálo, copialo y pegalo acá arriba. GitHub lo muestra una sola vez.
                      6. 
        
                    
        
                    Si la cuenta es un grupo (organización) y GitHub no te deja, el grupo tiene que permitir los tokens de grano fino en sus opciones. La otra salida es un token clásico con el permiso repo, que también sirve pero alcanza a todos tus repositorios.
